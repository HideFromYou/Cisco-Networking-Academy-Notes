# Cisco Networking Academy Notes

Personal notes from my journey through the **Cisco Networking Academy** e-learning programs, taken via **E-Learning NKUA** (National and Kapodistrian University of Athens).

## About

This repository contains my notes, key concepts, and practical takeaways while progressing through two sequential Cisco Networking Academy certification-prep programs:

1. **Networking Essentials** — prepares for the **Cisco Certified Support Technician (CCST) Networking** certification
2. **Cybersecurity Essentials** — prepares for the **Cisco Certified Support Technician (CCST) Cybersecurity** certification (starts after Networking Essentials is complete)

The goal is not only to complete the content, but to understand how networks and network security actually work — reinforcing what I'm also building in parallel through [HTB Academy's CPTS path](https://github.com/HideFromYou/Hack-The-Box-Notes).
