# Module 6: Network Media

## Overview

**Module objective:** Explain the characteristics and uses of common network media and how to select the appropriate medium for a network.

Network media carries data between network devices. The choice of medium affects distance, performance, reliability, installation requirements, and cost.

## Key Takeaways

- The three broad network media types are copper cable, fiber-optic cable, and wireless.
- Copper carries electrical signals; fiber carries light; wireless uses electromagnetic waves.
- Media selection depends on maximum distance, environment, required data rate, and total cost, including installation.
- Twisted-pair cabling is widely used in Ethernet LANs. Its twisted conductor pairs help reduce electromagnetic interference (EMI) and crosstalk.
- Coaxial cable uses a central conductor, dielectric insulation, metallic shielding, and an outer jacket. It is common in cable television and broadband distribution.
- Fiber-optic cable transmits light through a glass or plastic core. It supports high bandwidth and long distances and is immune to electromagnetic interference, but termination and splicing require specialized skills and care.
