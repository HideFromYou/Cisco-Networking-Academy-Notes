# Network Components

## Overview

Covers the physical building blocks of a network: the network infrastructure and its three categories of hardware (end devices, intermediate devices, network media), with a closer look at end devices.

## Learning Objectives

- Explain the roles of network infrastructure devices
- Name the three categories of network hardware
- Describe end devices and how hosts are identified

## Network Infrastructure Symbols (2.2.1 video)

Network diagrams use a standard set of symbols for the three hardware categories: desktop, laptop, printer, IP phone, tablet and TelePresence endpoint for end devices; wireless router, LAN switch, router, multilayer switch and firewall appliance for intermediate devices; and distinct line styles for wireless (waves), LAN (solid line) and WAN (lightning bolt) media.

## Network Infrastructure

The path a message takes from source to destination can be a single cable between two computers or a network spanning the globe. The **network infrastructure** is the platform that supports the network, providing the stable and reliable channel for communication.

It contains three categories of hardware components:

| Category | Examples |
|---|---|
| **End devices** | Desktop computer, laptop, printer, IP phone, wireless tablet, TelePresence endpoint |
| **Intermediate devices** | Wireless router, LAN switch, router, multilayer switch, firewall appliance |
| **Network media** | Wireless media, LAN media (cabling), WAN media |

Devices and media are the physical elements (hardware) of the network: laptop, PC, switch, router, wireless access point, cabling. Some components are not visible — wireless media carries messages through the air using radio frequencies or infrared waves.

## End Devices

End devices (also called **hosts**) are the devices people are most familiar with; they form the **interface between users and the underlying communication network**.

Examples:

- Computers (workstations, laptops, file servers, web servers)
- Network printers
- Telephones and teleconferencing equipment
- Security cameras
- Mobile devices (smartphones, tablets, PDAs, wireless debit/credit card readers, barcode scanners)

An end device is either the **source or the destination** of a message sent over the network. Hosts are uniquely identified by **addresses**: when a host starts communication, it uses the destination host's address to specify where the message should go.

**Data flow:** data originates at an end device, flows through the network (LAN switch → edge router → internetwork of routers → edge router → LAN switch), and arrives at the destination end device. Messages can take alternate routes through the internetwork.

## Key Takeaways

- Network hardware falls into three categories: end devices, intermediate devices, and network media.
- End devices (hosts) are where data starts and ends; they connect users to the network and are identified by addresses.
- Messages between end devices pass through intermediate devices and can take alternate routes across an internetwork.
