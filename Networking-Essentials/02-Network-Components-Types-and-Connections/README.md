# Module 2: Network Components, Types, and Connections

## Overview

**Module objective:** Explain network types, components, and connections.

The module introduces the roles of the things that make up a network: end devices (hosts), intermediate devices, and network media. The motivating scenario: notes typed on one device (a laptop) appearing on another (a desktop) and reaching the internet — how are all these devices connected?

## Key Takeaways

- Client and server are software roles on a host, and one host can hold several of each at the same time.
- Peer-to-peer networks are simple and cheap but lack central administration, security, and scalability, so larger networks use dedicated servers.
