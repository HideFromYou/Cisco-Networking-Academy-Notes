# Network Components, Types, and Connections — Summary

## Overview

End-of-module recap (2.4.1 "What Did I Learn in this Module?"). It restates the three topics of the module; the details live in their own sections.

## Recap

- **Clients and Servers** — All computers that take part directly in network communication are hosts, and hosts can send and receive messages. A host can act as a client, a server, or both; the installed software decides the role. Client and server software usually run on separate computers, but one computer can run both. In small businesses and homes many computers act as both, which is a **P2P network**: easy to set up, less complex, lower cost, good for simple tasks like transferring files and sharing printers, but with no centralized administration, less security, no scalability, and slower performance. Larger businesses need dedicated servers because of the volume of traffic. → see [01-Clients-and-Servers](../01-Clients-and-Servers/README.md)
- **Network Components** — Symbols represent the different types of networking equipment. The network infrastructure is the platform that supports the network, with three categories of hardware: end devices, intermediate devices, and network media. Hardware is often visible (laptop, PC, switch, router, wireless access point, cabling); wireless media is the component you can't see. End devices (hosts) form the interface between users and the network: computers, network printers, telephones and teleconferencing equipment, security cameras, and mobile devices. → see [02-Network-Components](../02-Network-Components/README.md)
- **ISP Connectivity Options** — An ISP links the home network to the internet and connects to other ISPs hierarchically so traffic takes the shortest path. The backbone is a web of fiber-optic cables with switches and routers. The most common home setup is a wireless integrated router (switch + wireless AP + client IP addressing + security) connected to the ISP. The two most common methods are cable and DSL; others are cellular, satellite, and dial-up telephone. → see [03-ISP-Connectivity-Options](../03-ISP-Connectivity-Options/README.md)
