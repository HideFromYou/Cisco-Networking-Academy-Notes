# Course Introduction

## Overview

**Networking Essentials** gives a broad foundational understanding of networking — how networks and the devices that make them up actually work, plus basic troubleshooting tools/techniques. It's intermediate-level: covers what's needed to build a home office network *and* a small Cisco office network, and prepares for moving into Cybersecurity or DevNet afterward.

## Scope / Progression

The course builds up in this order:

1. **Foundations** — core networking concepts, home/small office network basics
2. **Deeper dive** — Ethernet, IP addressing, the transport layer (bridge toward Cybersecurity/DevNet)
3. **Cisco device configuration** — ends with being able to configure and troubleshoot a small Cisco network
4. **Physical/data link/network layer depth** — topologies, basic routing
5. **IPv6** — static and dynamic addressing, address resolution
6. **Cisco switches and routers** — components and functionality
7. **Troubleshooting methodology** — common networking issues
8. **Customer support** — how to actually support users with this knowledge

## Recommended (not mandatory) prep

The course involves reviewing hardware and configuring network settings across different devices/OSs. Cisco recommends some basic prior knowledge of computer hardware and operating systems (Windows, Linux, mobile) — covered by two short separate Networking Academy courses:

- **Computer Hardware Basics**
- **Operating Systems Basics**

## Tools & Resources

- Course is accessible from phone/tablet/desktop, but **Packet Tracer activities, quizzes, and exams are best done on a PC**.
- **Help/FAQ:** netacad.com/help, or the Help link in the top nav. Packet Tracer download help specifically: netacad.com/resources/lab-downloads → Learning Resources section.
