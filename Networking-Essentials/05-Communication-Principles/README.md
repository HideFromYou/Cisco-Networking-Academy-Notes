# Module 5: Communication Principles

## Overview

**Module objective:** Explain the importance of standards and protocols in network communications.

The module explains how devices communicate by following agreed rules (protocols), why common standards are necessary for interoperability, and how layered network communication models help describe the interaction between protocols. The motivating scenario (5.0.1): two people who speak different native languages can communicate because they share English and agree on a method of communication and confirmation. Network devices similarly need shared rules to exchange information successfully.

## Key Takeaways

- Network protocols are agreed rules that govern communication between devices. They define aspects such as message format, message size, timing, encoding, encapsulation, and message patterns.
- Successful communication requires an identified sender and receiver, an agreed communication method, a common language or format, suitable timing, and any required acknowledgment.
- Network standards ensure that devices and products from different manufacturers can communicate by implementing common rules in the same way.
- Internet standards are developed through discussion, problem solving, and testing. RFC documents record the development and publication of Internet standards; the IETF manages their publication.
- A protocol stack is a layered set of protocols. Each protocol performs a particular task and relies on services provided by lower layers.
- The TCP/IP model has four layers: Application, Transport, Internet, and Network Access.
- The OSI reference model has seven layers: Application, Presentation, Session, Transport, Network, Data Link, and Physical.
- TCP/IP Transport maps to OSI Layer 4 (Transport), and TCP/IP Internet maps to OSI Layer 3 (Network). TCP/IP Application covers OSI Layers 5–7, while TCP/IP Network Access covers OSI Layers 1–2.
