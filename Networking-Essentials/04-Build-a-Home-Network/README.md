# Module 4: Build a Home Network

## Overview

**Module objective:** Configure an integrated wireless router and wireless client to connect securely to the internet.

The module covers how a home network is built: its basic structure, the wired and wireless technologies used in the home, Wi-Fi and its router settings, and how to set up a home router securely. The motivating scenario (4.0.1): a tablet that works over the home Wi-Fi rather than a mobile network, coming from the "box in the corner", which is the **home router**. Home routers typically have two primary types of ports (Ethernet and internet) and often a radio antenna with a built-in wireless access point. Someone who doesn't know what the router is probably never changed its **default password**, so the router's settings need to be changed to keep the network and its devices safer.

## Key Takeaways

- A home network is a small LAN behind an integrated router (wired ports + wireless access point), separate from the public network coming from the service provider.
- Home Wi-Fi uses the unlicensed 2.4 GHz and 5 GHz bands under the IEEE 802.11 standards (Wi-Fi); wired devices use Ethernet over Cat 5e UTP, or powerline where there is no cabling.
- Key router settings: network mode, SSID, channel (Auto by default), SSID broadcast. Don't put the device model or brand in the SSID, and change the router's default password.
- MAC address filtering and guest access are options to control who joins the network.
