# Data Transmission

## Overview

Covers how data is classified and how it physically travels across a network: the three categories of personal data, the bit as the smallest unit of data, and the three common methods of signal transmission.

> Note: written from the module's end-of-module summary (1.4.1). The individual 1.2 lesson pages can be added here if more detail is needed.

## Learning Objectives

- Classify types of personal data
- Define a bit
- Distinguish electrical, optical, and wireless signal transmission

## Types of Personal Data

| Category | Description | Example |
|---|---|---|
| **Volunteered data** | Created and explicitly shared by individuals | Social network profiles; video, pictures, text, audio files |
| **Observed data** | Captured by recording the actions of individuals | Location data from cell phones |
| **Inferred data** | Derived from analysis of volunteered or observed data | A credit score |

## The Bit

**Bit** = abbreviation of "binary digit" — the smallest piece of data. A bit has only one of two possible values: **0 or 1**.

## Signal Transmission Methods

| Method | How data is transmitted |
|---|---|
| **Electrical signals** | Data represented as electrical pulses on copper wire |
| **Optical signals** | Electrical signals converted into light pulses |
| **Wireless signals** | Infrared, microwave, or radio waves through the air |

## Key Takeaways

- Personal data splits into volunteered (shared on purpose), observed (recorded from behavior), and inferred (derived from the first two).
- Everything on a network ultimately reduces to bits (0/1), carried as electrical pulses, light pulses, or radio-type waves.
- The medium (copper, fiber, air) determines which signal type is used — and, as covered in Bandwidth and Throughput, how much bandwidth is available.
